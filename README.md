# Альфа Принт

Сайт типографии и рекламного агентства «Альфа Принт» — Нальчик, ул. Тарчокова, 29.
Работает с 2014 года. 4,8 из 5 по 44 отзывам на Яндекс.Картах.

Сейчас собрана **только главная страница**. Остальные разделы ещё не свёрстаны —
пункты меню временно ведут на секции главной.

---

## Идея: приводка

Всё ремесло типографии — в том, чтобы свести разное в одну точку: четыре краски,
линию реза, срок. Отсюда один закон, которому подчиняется вся страница:

> **всё приходит не в приводке и сходится под взглядом.**

Не сведённый набор значит «лист ещё в машине». Сведённый — «заказ сдан».
Заголовок первой полосы сводится при загрузке: сайт печатает собственный заголовок.
Строки каталога сходятся под курсором. Знак в подвале не сводится никогда — и об
этом там написано отдельной строкой.

### Три правила, которые нигде не нарушаются

1. **Одна тень.** Тень бывает только у блока, который вырезали из листа (`.is-cut`).
   Всё остальное разделяется волосяной линией в 1px. Тень — событие, а не оформление.
2. **Триада в карантине.** `--color-proc-c/m/y` живут только внутри механизма:
   приводка, контрольная шкала, растровая розетка. Они никогда не красят текст и
   никогда не становятся фирменным цветом.
3. **Одна краска.** Рубин `#d4003c` — единственный акцент на весь сайт.

Единственная оговорка к первому правилу — секция «Оттиск»: там `text-shadow`
рисует ожог и фаску тиснения, то есть след инструмента в материале, а не высоту
над плоскостью.

## Типографика

Три гарнитуры, у всех настоящая кириллица, все переменные.

| Роль | Гарнитура | Оси |
| --- | --- | --- |
| Дисплейная | **Roboto Serif** | `opsz 8…144`, `wdth 50…150`, `wght 100…900`, `GRAD` |
| Текст и интерфейс | **Geologica** | `SHRP 0…100`, `wght`, `CRSV`, `slnt` |
| Технический слой | **Geist Mono** | `wght` |

Оси здесь не украшение, а инструмент:

- **Выключка по оси ширины** (`src/components/ui/Justified.tsx`). Наборщик веками
  выключал строку в формат шпациями, то есть портил межбуквенные пробелы. Здесь
  для каждой строки бинарным поиском подбирается своя `wdth`, пока строка не
  совпадёт с форматом полосы. Трекинг не трогается вообще. В металле так было
  нельзя.
- **Настоящий оптический кегль** («Кегельная лестница», секция 04). Девять ступеней
  от баннера 3×6 м до мелкого шрифта на упаковке, и у каждой своя `opsz` —
  крупные кегли набраны тонким рисунком, мелкие плотным, как резали до
  фотонабора. Размер задан честным `font-size`, а не `transform: scale()`:
  масштаб растянул бы одну и ту же букву и весь смысл лестницы пропал бы.

градиентами, повторами и обрезкой по контуру букв.

## Стек

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 ·
Motion (Framer Motion v12) · Lenis.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run typecheck
```

### Где что лежит

```
src/
  app/            layout, globals.css (вся дизайн-система), fonts.ts, icon.svg
  components/
    layout/       Header, Footer
    sections/     десять секций главной
    ui/           Registration, Justified, PrintMarks, Cursor, Sushka
    providers/    SmoothScroll, Motion
  content/site.ts единственный источник правды по данным «Альфы»
  lib/            cn, hooks, naryad
```

Все факты — телефоны, адрес, отзывы, реквизиты — живут только в
`src/content/site.ts`. В разметке их дублировать нельзя.

## Доступность и производительность

- Один `h1`, сплошная иерархия заголовков, ориентиры `header/main/footer/nav`, `lang="ru"`.
- Цветные формы приводки помечены `aria-hidden` и `select-none`: скринридер и
  копирование видят один текстовый узел.
- Контраст проверен по WCAG AA на всей странице.
- `MotionConfig reducedMotion="user"` плюс CSS-правило: при системной настройке
  «уменьшить движение» сдвиги отключаются, прозрачность доигрывает — ни один
  блок не остаётся невидимым.
- Анимируются только `transform` и `opacity`. Плавная прокрутка выключается на
  тач-устройствах и в покое.
- Разметка `LocalBusiness` со всеми реквизитами, часами и рейтингом.

## Заглушки

- Раздел «Работы» — шесть пробных форм вместо фотографий. Формы подписаны
  «съёмка готовится» и заменяются на реальные снимки в `WORKS` (`src/content/site.ts`).
- Часы работы в `COMPANY.hours` проставлены типовые — заменить на настоящие.
- Домен в `SITE` (`src/app/layout.tsx`) и `og.png` — временные.
